How to install

Kite is not on the Play Store, so your phone will ask you to allow installing it. This is normal for any app installed outside the store.

  1. Tap the download button above to save the APK file.
  2. Open the downloaded file from your notifications or Downloads folder.
  3. If asked, allow your browser or file manager to install unknown apps, then confirm the install.

Kite never asks for anything beyond what it needs to run as your launcher. Nothing is collected during or after installation.
